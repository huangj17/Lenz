# Lenz v0.1.4

修复 Windows 托盘图标显示为黑色的问题。应用「关于」、EXE 安装器/卸载项和文件名均升级为 **0.1.4**,MSIX 包版本为 **0.1.4.0**。

## 更新内容

- Windows 托盘改用彩色应用图标,避免黑色模板在深色任务栏上难以辨认。macOS 继续使用由系统适配深浅色的单色模板。
- 普通 EXE 与 MSIX 均包含此修复,并保留此前的翻译弹框持续加宽、启动时进程退出等修复。
- 普通 EXE 无需导入证书、不强制安装本地 OCR;安装后可直接配置腾讯云等服务。需要 Windows 系统 OCR 时,保留可选 MSIX 入口。
- EXE、MSIX 和两种 macOS DMG 均从本版本源码重新构建。

## 下载与升级

- **Windows x64 普通 EXE（推荐）**:[Lenz_0.1.4_windows_x64_setup.exe](https://github.com/huangj17/Lenz/releases/download/v0.1.4/Lenz_0.1.4_windows_x64_setup.exe)。完全退出旧版 Lenz 后覆盖安装,本机配置会保留;安装后在「关于」确认版本为 0.1.4。
- **Windows x64 MSIX（系统 OCR 可选版）**:[Lenz_0.1.4_windows_x64_test-signed.zip](https://github.com/huangj17/Lenz/releases/download/v0.1.4/Lenz_0.1.4_windows_x64_test-signed.zip)。内含 `Lenz-0.1.4.0-x64.msix`、公开测试证书及安装助手,步骤见 [Windows 分发指南](https://github.com/huangj17/Lenz/blob/main/docs/windows-distribution.md)。普通 EXE 使用腾讯云无需此证书或本地 OCR 语言包。
- **macOS Apple Silicon**:[Lenz_0.1.4_aarch64.dmg](https://github.com/huangj17/Lenz/releases/download/v0.1.4/Lenz_0.1.4_aarch64.dmg)。
- **macOS Intel**:[Lenz_0.1.4_x64.dmg](https://github.com/huangj17/Lenz/releases/download/v0.1.4/Lenz_0.1.4_x64.dmg)。
- [SHA256SUMS.txt](https://github.com/huangj17/Lenz/releases/download/v0.1.4/SHA256SUMS.txt) 提供五项安装附件的校验值。

Windows 最低版本为 Windows 10 1809,macOS 最低为 macOS 12。Windows EXE 尚无公开可信签名,MSIX 使用自签测试证书;macOS 使用 ad-hoc 签名,尚未完成公证。安装助手不会自动信任 MSIX 证书。
