# Lenz v0.1.5

改善了 macOS 桌面应用的划词取词。没有选中文字时，也可以用翻译快捷键打开输入弹框。

- macOS 增加对原生选区范围和 WebKit 选区的读取支持。应用无法直接提供选区时，Lenz 会尝试复制并恢复原剪贴板内容。
- 按 `⌥D` / `Alt+D` 未取得选区时，弹框会聚焦空白输入框。输入后可按回车或点击「翻译」，用 `Shift+Enter` 换行。
- macOS 本机构建可通过 `pnpm macos:local` 复用固定自签证书。macOS 27.2 上已验证两份同证书构建往返替换后，设备控制和录屏权限仍然有效。[本机签名与升级验收](https://github.com/huangj17/Lenz/blob/v0.1.5/docs/macos-signing.md)

## 下载与升级

- macOS Apple Silicon 使用 [Lenz_0.1.5_aarch64.dmg](https://github.com/huangj17/Lenz/releases/download/v0.1.5/Lenz_0.1.5_aarch64.dmg)。
- macOS Intel 使用 [Lenz_0.1.5_x64.dmg](https://github.com/huangj17/Lenz/releases/download/v0.1.5/Lenz_0.1.5_x64.dmg)。
- Windows x64 可使用 [普通 EXE 安装包](https://github.com/huangj17/Lenz/releases/download/v0.1.5/Lenz_0.1.5_windows_x64_setup.exe)。
- 需要 Windows 系统 OCR 时，可使用 [MSIX 和安装助手 ZIP](https://github.com/huangj17/Lenz/releases/download/v0.1.5/Lenz_0.1.5_windows_x64_test-signed.zip)，按指南检查并导入公开测试证书。[Windows 分发指南](https://github.com/huangj17/Lenz/blob/v0.1.5/docs/windows-distribution.md)
- 安装文件的校验值见 [SHA256SUMS.txt](https://github.com/huangj17/Lenz/releases/download/v0.1.5/SHA256SUMS.txt)。

最低系统版本为 macOS 12 和 Windows 10 1809。公开 macOS DMG 使用临时签名，覆盖安装后可能需要重新授权。已经配置固定本机证书的用户，可从源码构建同证书更新包。

## 实测范围

macOS 实机用 Sublime Text 和本机模拟服务验证了选区翻译，也验证了空白弹框、手动输入和回车提交。Sublime Text 在无选区时会复制当前行，Lenz 在这种情况下仍可能直接翻译该行。其他邮件和聊天应用、Windows 客户端的划词与输入、多屏交互仍待逐一验证。[验收记录](https://github.com/huangj17/Lenz/blob/v0.1.5/docs/TODO.md)
