# Lenz v0.1.2

新增腾讯云高精度 OCR,修复 macOS 快捷键取词与选区弹窗定位,并更新应用图标和权限提示。

## 更新内容

- **腾讯云 OCR**:在“服务 → OCR”添加腾讯云服务,填写 SecretId / SecretKey,选择通用中英文或多语种场景,支持最低置信度、超时和内置样例测试。设为默认 OCR 后,截图翻译和原图覆盖翻译都会使用腾讯云;调用失败不会自动切换其他 OCR 服务。
- **覆盖位置**:腾讯云识别使用原图文字坐标回映射到屏幕,处理 Retina 缩放、负屏幕坐标及边界裁剪,避免误用旋转纠正后的坐标造成覆盖偏移。
- **取词可靠性**:macOS 快捷键取词绑定触发时的前台应用,处理剪贴板多格式写入与修饰键状态。无法读取选区时明确提示原因,避免展示无关的旧翻译。
- **弹窗定位**:划词弹窗优先在选中文字下方居中,空间不足时移到上方。内容增减保持选区锚点,手动拖动后沿用用户位置。
- **权限提示**:中英文界面说明新旧 macOS 辅助功能权限名称;已开启但仍无法检测时,提示重新添加当前安装的 Lenz。
- **应用图标**:桌面和安装包使用冰蓝至浅蓝紫的渐变圆角底板,窗口内品牌标记保持透明背景。
- **配置兼容**:自动迁移至 schema v8,保留已有 OCR/翻译服务、凭据、默认选择和语言偏好。
- **Windows EXE 启动修复（2026-10-16）**:修复前端早于后端初始化发送请求造成的启动崩溃;开始菜单和安装完成页明确显示主窗口。主线程致命错误会显示提示并保留启动日志。此热修复针对由 [93e3474](https://github.com/huangj17/Lenz/commit/93e3474c18a889d531c56c1f7b9279be4417b3e9) 重新编译的普通 EXE 附件;MSIX 和 macOS 附件保留原构建。

## 下载与安装

- **macOS Apple Silicon**:`Lenz_0.1.2_aarch64.dmg`。
- **macOS Intel**:`Lenz_0.1.2_x64.dmg`。最低 macOS 12;Apple 翻译需要 macOS 15+ 及对应语言包。
- **Windows x64 普通 EXE 安装包**（2026-10-16 更新）:`Lenz_0.1.2_windows_x64_setup.exe`,直接安装应用文件,无需手动导入证书。安装后在「设置 → 服务 → OCR」添加腾讯云并设为默认,无需本地 OCR 语言包。包含开始菜单和卸载程序;缺少 WebView2 时下载并验证微软官方运行环境。EXE 无公开可信签名,可能显示 SmartScreen/未知发布者提示。
- **Windows x64 MSIX + 安装助手（系统 OCR 可选版）**:`Lenz_0.1.2_windows_x64_test-signed.zip`,内含 MSIX、公开测试证书和安装助手。最低 Windows 10 1809,具体步骤见 [Windows 分发指南](https://github.com/huangj17/Lenz/blob/main/docs/windows-distribution.md)。
- `SHA256SUMS.txt` 提供安装产物的 SHA256 校验值。

macOS 仍使用 ad-hoc 签名,尚未完成 Developer ID 签名与公证。Windows 普通 EXE 无需导入证书;可选 MSIX 使用自签测试证书,安装前需检查并手动信任公开 `.cer`,安装助手不会自动修改证书信任。安装新版后如辅助功能授权未生效,请在系统隐私设置中重新添加当前安装的 Lenz。


Windows 本地 OCR 为可选能力。普通 EXE 不部署 MSIX,可直接配置腾讯云等服务。以后需要系统 OCR 时,再安装并从 MSIX 入口运行 Lenz,完成测试证书信任和 Windows OCR 语言包设置;仅导入证书不能给普通 EXE 增加包身份。切换前请退出旧实例,建议卸载普通 EXE 以区分启动入口。Windows 10/11 用户机器、升级/卸载、跨安装形式切换和腾讯云真实识别仍待实测。

默认使用系统 OCR。选择腾讯云后,截图会上传腾讯云,需要自行开通服务并配置有效凭据;凭据目前明文保存在本机配置中。视觉模型仍只用于截图翻译,选为默认时原图覆盖继续使用系统 OCR。
