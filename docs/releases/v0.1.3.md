# Lenz v0.1.3

本版本将近期 Windows 修复以独立版本重新构建发布。应用「关于」、EXE 安装向导/卸载项和下载文件名均为 **0.1.3**,MSIX 包版本为 **0.1.3.0**,方便与此前的 v0.1.2 安装包区分。

## 更新内容

- 修复 Windows 快捷键翻译后弹框持续加宽的问题:调整尺寸时保持内容区的另一维,避免系统隐形边框反复累加;保留 300~720 的手动调宽和宽度记忆。
- 包含 Windows 启动修复:在创建窗口前完成后端状态准备,避免首轮请求导致进程退出;开始菜单和安装完成页明确显示主窗口,致命启动错误保留独立日志。
- 普通 EXE 直接安装应用,无需导入证书、不强制安装本地 OCR。安装后可配置腾讯云等服务;保留可选 MSIX 下载入口。
- EXE、MSIX 和两种 macOS DMG 均从本版本源码重新构建,包含已有腾讯云高精度 OCR 和配置兼容能力。

## 下载与升级

- **Windows x64 普通 EXE（推荐）**:[Lenz_0.1.3_windows_x64_setup.exe](https://github.com/huangj17/Lenz/releases/download/v0.1.3/Lenz_0.1.3_windows_x64_setup.exe)。完全退出旧版 Lenz 后覆盖安装,本机配置会保留;安装后在「关于」确认版本为 0.1.3。
- **Windows x64 MSIX（系统 OCR 可选版）**:[Lenz_0.1.3_windows_x64_test-signed.zip](https://github.com/huangj17/Lenz/releases/download/v0.1.3/Lenz_0.1.3_windows_x64_test-signed.zip)。内含 `Lenz-0.1.3.0-x64.msix`、公开测试证书及安装助手,具体步骤见 [Windows 分发指南](https://github.com/huangj17/Lenz/blob/main/docs/windows-distribution.md)。仅需要系统 OCR 时切换;普通 EXE 使用腾讯云无需导入证书或安装本地语言包。
- **macOS Apple Silicon**:[Lenz_0.1.3_aarch64.dmg](https://github.com/huangj17/Lenz/releases/download/v0.1.3/Lenz_0.1.3_aarch64.dmg)。
- **macOS Intel**:[Lenz_0.1.3_x64.dmg](https://github.com/huangj17/Lenz/releases/download/v0.1.3/Lenz_0.1.3_x64.dmg)。
- [SHA256SUMS.txt](https://github.com/huangj17/Lenz/releases/download/v0.1.3/SHA256SUMS.txt) 提供五项安装附件的校验值。

Windows 最低版本为 Windows 10 1809,macOS 最低为 macOS 12。Windows EXE 尚无公开可信签名,MSIX 使用自签测试证书;macOS 使用 ad-hoc 签名,尚未完成公证。证书信任与本地 OCR 均为 MSIX 入口的单独步骤,安装助手不自动信任证书。
