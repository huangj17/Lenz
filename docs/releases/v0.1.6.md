# Lenz v0.1.6

修复一轮代码审查发现的隐私、剪贴板、窗口和快捷键问题，并收紧发布流程。

- 隐私：OpenAI 兼容引擎必须填写 API URL，地址为空时不会再默认发往 api.openai.com，「测试」也不会发出请求。新添加的引擎默认停用，填好地址和模型后再启用。
- Windows 划词：先等 `Alt` 等修饰键松开再复制，避免变成 `Ctrl+Alt+C`（AltGr 键盘布局下曾会输入字符替换选中文字）。复制回退中途被打断，比如移动鼠标、剪贴板历史工具占用剪贴板，或应用复制较慢，都会恢复原剪贴板内容，不再被选中文字替换。
- 重复启动只保留一个 Lenz：已在后台运行时再从开始菜单或程序图标打开，会显示已运行实例的设置窗口，不会出现两个托盘图标或两份配置互相覆盖。
- Windows 上在翻译弹框按 `Alt+F4` 只会关闭本次翻译，之后仍可正常弹出。关闭任一屏的截图选区会取消整个选区。
- 某个快捷键被其他程序占用时，其余快捷键照常可用；被占用的键会在下次应用快捷键设置时重试，也不影响修改其他快捷键。
- macOS 未授予「屏幕录制」时，截图翻译会弹出系统授权请求，并在弹框中提示前往系统设置授权，不再只显示「失败」或「未识别到文字」。
- 发布流程：标签须先通过 CI（类型检查、测试、Clippy）才会上传安装包；已公开的版本不会被重新构建静默覆盖；只有最高版本会被标记为 Latest。

## 下载与升级

- macOS Apple Silicon 使用 [Lenz_0.1.6_aarch64.dmg](https://github.com/huangj17/Lenz/releases/download/v0.1.6/Lenz_0.1.6_aarch64.dmg)。
- macOS Intel 使用 [Lenz_0.1.6_x64.dmg](https://github.com/huangj17/Lenz/releases/download/v0.1.6/Lenz_0.1.6_x64.dmg)。
- Windows x64 可使用 [普通 EXE 安装包](https://github.com/huangj17/Lenz/releases/download/v0.1.6/Lenz_0.1.6_windows_x64_setup.exe)。
- 需要 Windows 系统 OCR 时，可使用 [MSIX 和安装助手 ZIP](https://github.com/huangj17/Lenz/releases/download/v0.1.6/Lenz_0.1.6_windows_x64_test-signed.zip)，按指南检查并导入公开测试证书。[Windows 分发指南](https://github.com/huangj17/Lenz/blob/v0.1.6/docs/windows-distribution.md)
- 安装文件的校验值见 [SHA256SUMS.txt](https://github.com/huangj17/Lenz/releases/download/v0.1.6/SHA256SUMS.txt)。

最低系统版本为 macOS 12 和 Windows 10 1809。公开 macOS DMG 使用临时签名，覆盖安装后可能需要重新授权。已经配置固定本机证书的用户，可从源码构建同证书更新包。
