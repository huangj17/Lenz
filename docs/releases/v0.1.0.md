# Lenz v0.1.0

首个公开安装包版本,包含划词翻译、截图翻译、原图覆盖翻译及完整设置页。

## 下载与安装

- **macOS Apple Silicon**:下载 `aarch64.dmg`,将 Lenz 拖入「应用程序」。
- **macOS Intel**:下载 `x64.dmg`,将 Lenz 拖入「应用程序」。最低 macOS 12。
- **Windows x64**:推荐下载 `windows_x64_test-signed.zip`,内含 MSIX、公开测试证书和安装助手。最低 Windows 10 1809;具体步骤见 [Windows 分发指南](https://github.com/huangj17/Lenz/blob/v0.1.0/docs/windows-distribution.md)。
- `SHA256SUMS.txt` 提供安装包 SHA256 校验值。

macOS 采用 ad-hoc 签名,尚未完成 Developer ID 签名和公证,首次打开可能需要在系统「隐私与安全性」中确认。划词监听和截图分别需要用户授予辅助功能、屏幕录制权限。

Windows 采用自签**测试证书**,并非公开可信的正式签名。安装前需检查并明确信任 ZIP 内的公开 `.cer`;助手不会自动修改证书信任。此发布证书有效期 365 天,不包含私钥。安装助手默认运行系统 OCR 自检,缺语言包时需补齐对应 OCR 能力后重试。

## 功能

- 设置快捷键:macOS `Command+,`,Windows `Ctrl+,`;托盘快捷键提示统一靠右。
- 设置搜索、中英界面、深浅主题、登录启动和启动窗口选项。
- 翻译引擎增删改、超时设置、连接测试及最近测试状态。
- OCR 模式、语言偏好及顺序、自动检测/系统语言回退和平台能力提示。
- 原图覆盖翻译:独立取消会话、颜色采样、字体适应、鼠标穿透和关闭流程。
- Windows 划词监听/UIA 与 MSIX 包身份、包内登录启动和 WebView2 安装助手。
- GitHub Release 更新检查,实际版本/构建日期及离线开源许可证。
- macOS 15+ Apple Translation 原生桥接。

## 验证范围

本地前端构建/类型检查、19 项纯逻辑测试、61 项 Rust 测试及 Windows GNU 交叉构建通过。macOS 独立 QA 应用验证过设置快捷键、配置持久化与关于/许可证流程。

Windows 安装、OCR、语言包和自启重登验收按本次发布安排推迟;构建安装包不代表这些功能已经实测。macOS Apple 跨语言翻译、系统权限、多屏及双平台覆盖层原生交互仍待验收。详情见 [TODO](https://github.com/huangj17/Lenz/blob/v0.1.0/docs/TODO.md)。
