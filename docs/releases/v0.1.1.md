# Lenz v0.1.1

本次更新完善多服务翻译对比、每服务折叠与状态记忆,修复苹果翻译首次使用等待超时,并新增可配置的 OCR 服务。

## 更新内容

- **多服务翻译对比**:划词/截图翻译按设置顺序展示全部启用服务。各服务独立显示译文、耗时、复制、错误和重试,单项失败不影响其他结果。
- **每服务折叠与记忆**:点击服务标题折叠/展开;右侧齿轮可分别设置“记住折叠状态”和“折叠时不自动翻译”。偏好重启后保留,跳过的服务展开后补译,已完成结果直接复用。点击标题同时关闭设置菜单。
- **独立取消**:折叠可取消对应服务的未完成请求,其余服务继续。新查询或关闭弹窗取消旧会话,迟到结果不会覆盖当前内容。
- **苹果翻译**:缺少语言包时立即提示下载源/目标语言,提供系统设置入口,避免 helper 窗口持续等待直到超时。连接测试错误完整换行展示。
- **OCR 服务管理**:可添加百度 OCR 和 OpenAI 兼容视觉模型,支持默认切换、超时、服务编辑和固定样例测试。截图翻译使用所选服务;视觉模型用于截图文字识别,原图覆盖自动回退系统 OCR,百度 OCR 使用含位置的标准/高精度接口。
- **原图覆盖交互**:截图完成后立即展示图片与识别/翻译进度,处理中可以取消;修复全局 Escape 关闭时的卡死和焦点问题。
- **OCR 超时**:分离截图和 OCR 的时间预算,为 macOS Vision 首次初始化保留等待时间,避免首次识别误报超时。
- **配置兼容**:自动迁移至 schema v7,保留已有翻译/OCR 服务、凭据、语言偏好和窗口设置。

## 下载与安装

- **macOS Apple Silicon**:下载 `Lenz_0.1.1_aarch64.dmg`。
- **macOS Intel**:下载 `Lenz_0.1.1_x64.dmg`。最低 macOS 12,Apple 翻译需要 macOS 15+ 及已安装的源/目标语言包。
- **Windows x64**:推荐 `Lenz_0.1.1_windows_x64_test-signed.zip`,内含 MSIX、公开测试证书和安装助手。最低 Windows 10 1809,详见 [Windows 分发指南](https://github.com/huangj17/Lenz/blob/v0.1.1/docs/windows-distribution.md)。
- `SHA256SUMS.txt` 提供所有安装产物的 SHA256 校验值。

macOS 仍使用 ad-hoc 签名,尚未完成 Developer ID 签名与公证。Windows 使用自签测试证书,安装前需检查并手动信任 ZIP 内的公开 `.cer`;安装助手不会自动修改证书信任。

如使用第三方 OCR,所选图片会发送给该服务;选择本地视觉模型或系统 OCR 可在本机处理。默认配置仍使用系统 OCR。

## 验证范围

本地 macOS 前端类型检查、生产构建、37 项前端纯逻辑测试和 84 项 Rust 测试通过;8 项依赖原生服务/本地模型的验收测试默认忽略。多服务对比、折叠/延迟翻译、偏好持久化、重启恢复及原生请求取消已通过独立 macOS 应用与 localhost 样例验证;菜单修正另经浏览器中英、深浅主题和窄窗验证。

Apple 英中翻译、缺少法语语言包时快速返回指引已有本机原生验证。OCR 服务的本地协议与界面经过验证,百度线上凭据/额度及真实视觉模型识别质量仍待验收。Windows 安装/OCR/自启、Intel 原生运行和多屏/权限完整回归仍未实测;跨平台安装包构建不能代替运行验收。详情见 [TODO](https://github.com/huangj17/Lenz/blob/v0.1.1/docs/TODO.md)。
