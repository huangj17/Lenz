## 实机验证边界

- 本次 Rust 构建和测试运行于 macOS;Windows 新增剪贴板模块另做了独立 Rust 类型检查,不代表 Windows 原生编译/运行通过。
- 尚未实测系统快捷键占用、多屏缩放、屏幕录制权限及各源应用的剪贴板行为。
- 剪贴板恢复会检测并让出已观察到的新写入/用户输入;跨进程剪贴板 API 不提供完整事务保证,需在常用源应用中验证富文本、图片与快速复制。无法完整备份时跳过兜底。
- 原生截图/OCR 阻塞调用不能强制中止;取消会阻止后续处理和结果投递。HTTP future 会释放,远端服务是否停止计算取决于服务端。
- 抓屏期间翻译浮层隐藏,可通过新请求取代旧请求;ESC 在选区或 popup 聚焦时生效。
